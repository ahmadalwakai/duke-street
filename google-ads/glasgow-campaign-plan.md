## Recommended Campaign Setup

Campaign name: DST | Search | Glasgow | Calls & Leads

Campaign type: Search

Goal: Leads

Primary conversions:
- Calls from call asset
- Website call clicks
- WhatsApp/message clicks
- Quote form submissions
- Thanks page lead event

Important tracking note:
The site currently fires events named `call_click`, `whatsapp_click`, `generate_lead`, and `lead_thanks`. The current `send_to` values in the code are placeholders such as `call`, `whatsapp`, and `lead_form`; before publishing, map these to real Google Ads conversion IDs/labels or configure the same events through GTM/GA4 import.

Budget:
- Starter test: GBP35/day
- Stronger emergency lead test: GBP70/day
- Keep campaign paused until conversion tracking is verified.

Bidding:
- If conversion tracking is verified: Maximize conversions.
- If conversion tracking is not verified yet: Maximize clicks with a CPC cap, then switch to Maximize conversions after reliable lead data is recorded.

Networks:
- Google Search: on
- Search partners: off for launch test, review after search term quality is proven
- Display network: off

Language:
- English

Location targeting:
- Target Glasgow, Scotland, United Kingdom.
- Add a 12-15 mile radius around 3, 10 Gateside St, Glasgow G31 1PD if the account allows radius targeting.
- Keep this as a Glasgow campaign. Create separate campaigns for Edinburgh and Dundee if needed.

Advanced location option:
- Use "Presence: people in or regularly in your targeted locations".
- Avoid the broader "Presence or interest" setting for this local emergency service unless you intentionally want people outside Glasgow researching Glasgow.

Ad schedule:
- 24 hours, 7 days, only if calls are genuinely answered 24/7.
- If call handling is weaker overnight, keep 24/7 ads live but lower bids overnight after data shows lead quality.

Devices:
- Mobile is the priority because emergency tyre searches often convert by phone.
- If using manual CPC or Maximize clicks, consider a mobile bid increase after launch data confirms stronger mobile conversion rate.
- If using smart bidding, avoid manual device bid changes unless Google Ads allows and data supports it.
